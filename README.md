# Claude Usage Efficiency

> **Claude 사용량 제한을 회피하지 않고**, 불필요한 대화 왕복·중복 컨텍스트·반복 첨부를 줄여 작업 효율을 높이기 위한 Manus 스킬입니다.

`claude-usage-efficiency`는 Claude에 보낼 요청을 **한 번에 완결된 작업 패킷**으로 구성하고, 관련 작업의 적절한 배치 처리, 현재 대화 및 프로젝트 지식의 재사용, 전송 전 품질 점검을 적용합니다. 이 스킬의 목적은 단순히 토큰이나 메시지를 줄이는 것이 아니라, 필요한 품질을 유지하면서 사용자의 원래 목표를 더 적은 불필요한 상호작용으로 달성하도록 돕는 것입니다.

| 항목 | 내용 |
|---|---|
| 대상 환경 | Manus 사용자 정의 스킬 |
| 주요 용도 | Claude 프롬프트 최적화, 사용량 제한 대응, 반복 컨텍스트·첨부 관리 |
| 적용 작업 | 코딩, 글쓰기, 리서치·분석, 파일 기반 작업 |
| 설계 원칙 | 공식 모범사례 준수, 품질 우선, 한도 우회 금지 |
| 핵심 파일 | `usage-efficiency-claude-ai.zip` |

## 왜 필요한가

Anthropic의 공식 안내에 따르면 Claude 사용량에는 메시지 길이, 첨부 파일 크기, 현재 대화의 길이, 도구 사용, 모델 선택, 노력 수준, 아티팩트 사용 등이 영향을 줄 수 있습니다.[1] 따라서 같은 정보를 반복 입력하거나, 모호한 요청을 여러 번 주고받거나, 반복 참조할 파일을 계속 첨부하는 방식은 피하는 것이 좋습니다.

이 스킬은 다음 원칙을 자동 적용하도록 작성되었습니다.

| 원칙 | 스킬의 적용 방식 |
|---|---|
| 사전 계획 | 목표·입력·제약·출력 형식·완료 기준을 먼저 정리합니다. |
| 구체적이고 간결한 지시 | 결과에 필요한 맥락만 포함하고, 재질문을 유발하는 모호성을 제거합니다. |
| 관련 작업 묶기 | 같은 자료와 목적을 공유하는 하위 작업을 한 요청으로 정리합니다. |
| 맥락 재사용 | 현재 대화, 프로젝트 지식, 기존 파일의 위치를 참조해 중복 전송을 줄입니다. |
| 프로젝트 지식 활용 | 자주 쓰는 문서와 기준 자료는 프로젝트에 두고 반복 사용하도록 권합니다. |
| 사용량 상태 대응 | 한도에 가까울 때 우선순위를 조정하며, 한도 우회가 아닌 공식 사용량 페이지 확인을 안내합니다. |

## 설치

이 저장소를 내려받거나 복제한 뒤, `claude-usage-efficiency` 폴더를 Manus의 사용자 스킬에 추가합니다. Manus 인터페이스에서 스킬 파일을 업로드할 수 있다면 `SKILL.md`가 포함된 폴더 또는 패키지를 추가하면 됩니다.

```bash
git clone https://github.com/<YOUR_GITHUB_ID>/claude-usage-efficiency.git
```

저장소 구조는 다음과 같습니다.

```text
claude-usage-efficiency/
├── README.md
└── SKILL.md
```

`SKILL.md`의 YAML 메타데이터에는 스킬 이름과 자동 적용 조건이 들어 있습니다. Claude 사용량 제한, 프롬프트 효율화, 반복 컨텍스트 재사용, 사용량 경고 대응 등과 관련된 요청에서 스킬이 적용되도록 설계되어 있습니다.

## 사용 예시

### 1. 코딩 작업

코드 조각을 여러 번 나누어 보내기보다, 실행 환경·오류 전문·기대 동작·관련 코드 전체를 함께 제공하도록 요청을 구조화합니다.

```text
React 18 + TypeScript + Vite 환경입니다.
아래 오류를 해결하고, 수정된 파일별 전체 코드를 제시해 주세요.

[오류 전문]
...

[관련 파일]
...

제약: 기존 API 인터페이스는 변경하지 말고, 수정 후 재현 절차와 검증 방법을 포함해 주세요.
```

### 2. 글쓰기 작업

대상 독자, 목적, 톤, 필수 요점, 전체 원문을 함께 제공해 후속 확인 메시지를 줄입니다.

```text
아래 보도자료를 B2B SaaS 잠재 고객용으로 수정해 주세요.

목적: 무료 체험 전환 유도
톤: 신뢰감 있고 간결하게
필수 요점: 보안 인증, 도입 기간, 고객 지원
출력: 제목 3개와 400~500자 본문
원문:
...
```

### 3. 리서치·분석 작업

연구 질문, 범위, 기간, 제공 데이터, 근거 기준과 원하는 출력 형식을 한 번에 명시합니다.

```text
연구 질문: 2024~2026년 국내 생성형 AI 도입 동향을 요약해 주세요.
범위: 기업 도입 사례와 규제 변화만 포함합니다.
근거 기준: 1차 출처 또는 신뢰할 수 있는 언론·연구기관을 우선합니다.
출력: 핵심 발견 5개, 출처 링크, 기업 실무자를 위한 시사점 표.
```

## 동작 방식

스킬은 요청을 받으면 우선 사용자의 실제 목표와 이미 제공된 맥락을 확인합니다. 같은 입력·목적·출력 형식을 공유하는 하위 작업은 하나의 번호 목록으로 묶고, 서로 무관하거나 단계별 승인이 필요한 작업은 분리합니다.

반복적으로 참조할 자료가 있으면 Claude 프로젝트 지식에 올려 재사용하도록 제안합니다. Anthropic은 프로젝트에 업로드된 콘텐츠와 유사한 프롬프트에 캐싱 이점이 있을 수 있다고 설명합니다.[1] 다만 캐싱을 절대적인 사용량 절감 수단으로 보장하지 않으며, 정확성과 안전에 필요한 분석을 사용량 절감을 이유로 생략하지 않습니다.

| 사용량 상태 | 권장 동작 |
|---|---|
| 여유 있음 | 완결된 요청 패킷을 구성해 작업을 진행합니다. |
| 한도 근접 | 필수 산출물을 우선하고, 이미 제공된 대화·프로젝트 지식을 참조하며 대용량 신규 첨부와 불필요한 도구 사용을 줄입니다. |
| 한도 도달 | 우회 방법을 제안하지 않습니다. 사용자가 공식 사용량 페이지에서 상태와 재설정 정보를 확인하도록 안내하고, 이후 바로 실행할 최종 요청 초안을 준비합니다. |

## 제한 사항 및 안전 원칙

이 스킬은 Claude 계정에 로그인하지 않으며, 사용량·플랜·재설정 시점을 자동 조회하거나 조작하지 않습니다. 정확한 현황은 사용자가 Claude의 **Settings > Usage**에서 직접 확인해야 합니다.[1]

또한 이 스킬은 사용량 제한의 우회, 다중 계정 활용, 비정상 자동화, 제한 회피를 지원하지 않습니다. 사용량을 관리할 때에도 사용자 요청의 정확성, 보안, 개인정보 보호, 인용 품질을 우선합니다.
